OBus Voice Link

Trusted-LAN/VPN test relay only. This local-first relay is live-only: OBus stores no audio recordings. It is not encrypted end-to-end; never expose it to the public internet.

Connect two PCs

Host PC: choose a room, enter the shared key configured on the host, then copy these connection details to the second PC.

Second PC:

  1. Open the copied link. If it says localhost, replace it with the host PC’s LAN IP address.
  2. Enter the copied room name and the same shared key.
  3. Click Connect, allow microphone access, then hold Hold to talk.

Waiting to connect.

Audio travels only while Hold to talk is pressed and is discarded after live relay. Use only a trusted LAN or VPN.
